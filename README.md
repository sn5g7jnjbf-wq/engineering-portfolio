## Project 1 — 行動に寄り添うスマートホーム

照明をスマートフォンから操作できるようにするだけでなく、ベッドやデスクへの移動をセンサーで検知し、生活の流れを止めずに必要な機器が動く環境を目指しました。

- Aqara FP2などを利用した在室・位置検知
- 夜間、ベッドに一定時間いると照明を消す自動化
- デスクにいるとモニターライトを点灯する自動化
- Apple Home、Homebridge、Home Assistantの利用経験
- 24時間稼働を考え、バッテリー非搭載の中古Windowsタブレットを選択
- Codexを利用してHome Assistant端末のバックライト問題を調査

バックライトの変更では、元のslot Aを復旧用として残し、slot Bへ変更を加えました。slot Bで完全消灯し、slot Aから元へ戻せることも実機で確認しています。技術的な理由を確認できていない部分は推測で説明していません。

→ [詳細を見る](projects/smart-home.md)

## Project 2 — 自宅サーバー

Minecraftを友人と遊ぶためにサーバーを構築したことが、PCとサーバーへ興味を持つきっかけでした。

- 普段使いPCで始めたMinecraftサーバーを、24時間稼働する専用PCへ移行
- ルーターのポートを直接開放せず、Secure Share Netを利用して外部接続
- 実家へProxmoxサーバーを設置
- AdGuard Homeを動かし、DNSによる広告・トラッカー対策に利用
- Tailscale、PC間ファイル共有の利用経験

OSやVM／LXCの区別など、まだ確認できていない仕様は詳細ページに明記しています。

→ [詳細を見る](projects/home-server.md)

## Project 3 — LAVIE Home Matter

通学前に確認するバス・地下鉄、授業、予定、天気を一つにまとめるため、固定設置するAndroidタブレット向けダッシュボードを制作しました。

最新版のソースでは、ダッシュボード、時計、予定、授業、交通、天気、家電、設定の8画面があります。

- Kotlin / Jetpack Compose / Material 3
- ViewModelとCompose stateによる画面状態管理
- Coroutinesによる非同期処理
- 徒歩・乗り換えを含めた大学への到着予定時刻計算
- アプリ上で編集できる授業時間割
- iCalendar（ICS）による予定取得
- Open-Meteoによる天気予報と端末内キャッシュ
- 常時表示、全画面、照度センサー連動

コードは主にCodexが実装しました。私は利用場面と画面構成を考え、APKを実機へ入れ、表示や操作の問題を見つけて修正を繰り返しました。MatterとHome Assistantは画面・処理を試作しましたが、実機接続に成功していないため完成機能とはしていません。

→ [詳細を見る](projects/lavie-home-matter.md)

## AIとの役割分担

| 自分が担当したこと | 主にCodexを利用したこと |
| --- | --- |
| 解決したい課題と利用場面の整理 | Androidコードの実装 |
| 必要な機能、優先順位、画面構成の検討 | 調査手順やコマンドの提案 |
| 実機での動作・表示確認 | エラー原因の候補整理と修正案 |
| 改善点の発見と具体的な追加指示 | APKのビルド・署名手順の整備 |
| 復旧方法を残すなどのリスク判断 | 技術資料と引き継ぎ情報の整理 |

AIが生成したコードをすべて理解しているとは言いません。生成されたものをそのまま完成とせず、実機で結果を確認し、問題を見つけ、改善することを重視しています。
