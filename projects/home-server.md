# 自宅サーバーの構築・運用

## 概要

Minecraftを友人と遊ぶためのサーバー構築をきっかけに、24時間稼働する専用PC、Proxmox、AdGuard Homeなどへ関心を広げてきました。

まだすべての構成を技術的に説明できる段階ではありませんが、必要な環境を自分で調べて構築し、実際に運用した経験をまとめています。

| 項目 | 内容 |
| --- | --- |
| きっかけ | 友人とMinecraftを遊べるサーバーを作りたい |
| 改善 | 普段使いPCから24時間稼働の専用PCへ移行 |
| 現在の構成 | 実家のProxmoxサーバーでAdGuard Homeを運用 |
| 外部接続 | Secure Share Netを利用し、ルーターのポートを直接開放しない構成を選択 |
| 未確認 | サーバーOS、AdGuard HomeがVM／LXCのどちらか、バックアップ方式 |

> **スクリーンショット:** IPアドレス、ホスト名、端末情報を隠した公開用画像を、確認後に追加予定です。

## Minecraftサーバー

### きっかけ

Minecraftを快適に遊びたいと思ったことが、PCへ興味を持つきっかけでした。その後、友人と一緒に遊べる環境を作るため、Minecraftサーバーを構築しました。

### 普段使いPCから専用PCへ

最初は普段使用しているPCでサーバーを動かしていました。しかし、そのPCを停止している間は友人が参加できません。

そこで、サーバーを24時間動かせる専用PCへ移行しました。構築時はYouTubeやWebサイトを参考にし、必要な手順を調べながら設定しました。

### 外部接続

友人が外部から接続できるよう、ルーターのポートを直接開放せず、Secure Share Netを利用しました。

サービスの詳しい仕組みやセキュリティ上の特徴は、面接前に公式情報を確認したうえで説明します。

## ProxmoxとAdGuard Home

実家にProxmoxを導入したサーバーを設置しています。現在はAdGuard Homeを動かし、DNSを利用して広告やトラッカーをブロックしています。

Proxmoxにより、1台の物理サーバー上で用途ごとの環境を分けて扱えます。ただし、AdGuard Homeを仮想マシンとLXCコンテナのどちらで動かしているかは、現在確認中です。

## その他の経験

TailscaleやPCを利用したファイル共有の経験もあります。使用した端末、目的、現在の稼働状況を整理できた段階で追記します。

## 工夫したこと

- 普段使いのPCとサーバーを分け、利用時間に左右されないようにした
- 自宅ルーターのポートを直接公開せず、別の接続方法を選んだ
- 必要になった段階で専用機や仮想化へ移行した
- 分からない部分は複数の解説を調べながら構築した

## 学んだこと

- 目的に応じて、普段使いPC、専用PC、仮想環境を使い分ける考え方
- 外部接続では、接続できることだけでなく、公開範囲を考える必要がある
- DNSを利用すると、ネットワーク全体の通信を制御できる
- 構築時の記録がないと、後から説明・変更・復旧することが難しくなる
